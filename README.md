# DS-A1: Data Provenance and Measurement Audit

**Course:** Data Science – Fall 2026

## Project Overview

This assignment examines the provenance, structure, measurement quality, and limitations of the UCI Student Performance dataset.

## Dataset

- Dataset: UCI Student Performance Dataset (Mathematics)
- File: `student-mat.csv`
- Observations: 395
- Variables: 33
- Outcome: `G3` (final mathematics grade, 0–20)
- Exposure: `studytime` (ordinal categories 1–4)

## Analysis

The notebook includes dataset inspection, a data dictionary, data quality checks, measurement considerations, potential leakage risks, and sensitivity analysis comparing students with lower and higher reported study time.

## Reproducibility

The repository contains the Jupyter notebook, the dataset, and the PDF report. Run the notebook from top to bottom using Python with the required libraries.

## Limitations

The dataset is observational. Self-reported study time may contain measurement error, and associations between study time and academic performance should not be interpreted as causal effects.
